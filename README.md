# SARA AI Assistant 🤖

A voice-controlled AI assistant built with Python and Gemini AI.

## Features
- Voice recognition
- Gemini AI powered answers with sarcastic personality
- Play videos on YouTube
- Open Google, YouTube, Apple Music
- Tell current time
- Mac native voice output

## Setup
1. Get free Gemini API key from aistudio.google.com
2. Run: export GEMINI_API_KEY="your-key"
3. Install requirements: pip install -r requirements.txt
4. Run: python3 main.py
